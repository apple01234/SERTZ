# 기억의 서약 복구·REA 적용 검증

2026-11-03. Node 24.19.0 / Next 16.1.3 / Phaser 4.2.1.

- npm test: 72개 통과, 실패 0. 캠페인 30개와 원래 회귀 검사를 포함한다.
- npx tsc --noEmit, npm run lint:strict: 통과.
- npm run build:next: 프로덕션 컴파일·타입·페이지 생성 통과. /camp 진입점 포함. 원본 public/assets 약 275MB, assets3d 약 4.7MB, assets3d_vfx 약 1.8MB를 보존한다. 예전의 약 16MB pruning은 철회했다.
- 개발 Chromium 복구 검사: 실제 방향/공격 프레임 변화, 대화 입력 잠금·스킵·카메라 복원, 보스 등장 중 오프라인 전투 시계 정지·스킵·줌 복원, 소품 내부 클릭 차단을 통과했다.
- 같은 복구 검사에서 원래 RPG의 3,000개 이상 texture, 실제 무기 장착·AP 소비, 집 가구 배치/회전/회수와 충돌 body 제거, 원래 보스 필드 진입·보스 생성, 본편 복귀 후 장비/AP 보존과 레거시 저장 바이트 보존을 확인했다. 진입 초기의 원래 전체 팩 로딩은 스토리 장면보다 오래 걸린다.
- 스킬의 준비/1회 발동/후딜/쿨타임·회피 취소, 모든 보스전 스폰과 회피 중 소품 충돌은 공유 순수 전투 코드에서 검사했다. 34개 장의 목표 위치 접근과 3종 실내 통로도 검사했다.
- 이미지 SHA-256·원본 152개 개별 애니메이션 파일과 6종 원본 보스 시트의 hash/grid를 검사했다. 보스 시트의 빈 clip을 임의로 그려 채우지 않았다.
- 원래 saveSoon이 저장 대신 자기 자신만 다시 예약하던 오류를 수정했다. 실제 메서드를 추출해 20회 연속 요청이 1회 기록되고 flush가 타이머를 취소하며 즉시 기록하는지 검사했다. 본편 복귀와 pagehide에서도 확정 저장한다.
- REA 기존 13개 배포본과 추가 JENNY의 정적 구조를 확인했다. JENNY 800개, Nefarius 77개, Feather Park 78개 스크립트는 GDRE 정적 복원 개수이며 모두의 의미를 해석하거나 실행했다는 주장이 아니다. 세부 읽은 함수·출처·Evidence ID·SHA-256은 REFERENCE_DEEP_ANALYSIS.md와 JSON에 있다.

프로덕션 standalone 산출물의 Chromium 전체 검사도 통과했다. 첫 장 완료·중복 보상·기존 저장 보존·새로고침, 실제 보스 공략·승리·본편 복귀, 390×844 터치 HUD, 저장 오류·백업 다운로드, 브라우저 3개와 실제 로컬 전투 서버를 사용한 협동·서명 보상·본편 복귀를 확인했다. 선택된 미디어 196개 항목은 standalone에서도 소스 해시와 일치하며 원래 RPG 팩도 존재했다.

실제 Vercel 배포의 커밋·READY 상태·공개 주소 검증은 DEPLOYMENT.md에 기록한다.

거점은 원래 가로 화면 안내를 유지한다. 세로 계속하기 이후 메뉴/가방을 추가 확인했고 상단 HP를 가리지 않도록 거점 메뉴 위치를 조정했다.

운영 계정 DB, 실제 Google 로그인/결제, 상시 협동 서버, 서명 APK/iOS/EXE 설치와 실기기 성능은 이번 검증 범위에 포함하지 않는다. 협동 브라우저 검사는 모의 계정 HTTP와 실제 로컬 Socket.IO/서명 서비스를 사용한다. GBA는 헤더, NightShift는 PE/readme 범위이며 14개 게임 전체를 플레이하거나 완전 역공학하지 않았다. JENNY의 전투 관련 선택 함수와 카메라/효과 수명은 읽었으나 스토리 컷씬 타임라인 전체를 해석하지 않았다.
